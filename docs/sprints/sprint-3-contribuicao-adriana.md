## 1. O que fiz

Nesta sprint, fui responsável pelo desenvolvimento da estrutura inicial do frontend do Horta Familiar, utilizando React, JavaScript, CSS e Vite.

**Principais contribuições:**

- Estruturação inicial do projeto frontend.
- Desenvolvimento das telas de login, cadastro e Dashboard.
- Implementação das interfaces de culturas, canteiros, plantios e insumos.
- Desenvolvimento das páginas de tarefas, movimentações, colheitas, produção e relatórios.
- Criação e organização de componentes reutilizáveis.
- Implementação da navegação com React Router.
- Utilização do `localStorage` para simular o armazenamento de dados.
